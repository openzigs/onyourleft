# On Your Left

A free, open alternative to Strava + Zwift for cycling: ride tracking, indoor smart-trainer control, and live sensor capture over ANT+ and Bluetooth Low Energy.

## Status

Planning. See the open epic and its sub-issues.

## Scope

- Web app + mobile/desktop clients
- Smart trainer control (Wahoo KICKR and other FTMS/FE-C trainers)
- Sensors: power meter pedals, heart rate monitors, cadence and speed
- Activity recording, upload, analysis and social features
